# Audit Trail Activity Log Viewer

## Project Overview

This is a Spring Boot based Audit Trail and Activity Log Viewer project.

Features:
- Create Audit Logs
- View Audit Logs
- REST APIs
- Security Configuration
- Caching
- Docker Support
- Email Service
- Scheduled Tasks

---

## Tech Stack

- Java 17
- Spring Boot
- PostgreSQL
- Docker
- Redis
- Maven

---

```text
src

```

```bash
mvn spring-boot:run
```
